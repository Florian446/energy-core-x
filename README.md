# Energy Core X

Minimalistisches Energie-Dashboard für Home Assistant, Jackery SolarVault 3 Pro und Shelly Pro 3EM.

## HACS-Installation

HACS kann nur ein öffentliches GitHub-Repository installieren.

1. Dieses Projekt in ein öffentliches GitHub-Repository namens `energy-core-x` hochladen.
2. HACS öffnen → Drei-Punkte-Menü → Benutzerdefinierte Repositories.
3. GitHub-URL eintragen.
4. Kategorie `Dashboard` wählen.
5. Repository hinzufügen und herunterladen.
6. Home Assistant neu laden.

Danach eine manuelle Karte mit dem Inhalt aus `lovelace-card.yaml` anlegen.
